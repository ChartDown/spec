Every player gets their part

Write > MD drums: and only the drummer has to read it. A note with no instrument, > MD:, is for the whole band. One chart, and nobody digs through the others' notes.

The key changes. The chart doesn't.

ChartDown is written in the Nashville Number System. When a different voice leads this Sunday and wants it a step up, every number stays put; each player picks the key when they read it. Need a lift for the last chorus? Write @key A.

Write it the way the band talks

Pushes, stabs, holds, repeats and cues for one pass. If you call it out at rehearsal, there is a short way to write it.

    Open, all the way down

    ChartDown is a specification, not an app's file format. Anyone can build a reader, an editor or a converter for it, and charts stay plain text you own.

      node conformance/run.mjs ./my-parser.mjs

      Write a small adapter for your parser and run every case in the suite. Node.js 18, nothing to install.

      A first bar written 4 {drums: in}, in the JSON form (shortened):

      {
  "number": 1,
  "beats": 4,
  "cues": [
    { "roles": ["drums"], "text": "in" }
  ],
  "items": [
    { "type": "chord", "root": "4",
      "degree": 5, "quality": "" }
  ]
}
