ChartDown is Markdown for band charts: the Nashville Number System in plain text, with the music director's cues for every player.

    Reading it in
    
          
    
        
    
        
    Numbers stay put when a different voice leads this Sunday. Each player picks the key when they read it. Need a lift for the last chorus? Write @key A.
    
      
    
    
    
  
    

  
    
    
    
      
    
        
    4Build
    
        
    Open, all the way down.
    
        
    ChartDown is a specification, not one app's file format. Anyone can build a reader, an editor or a converter, and your charts stay plain text you own.
